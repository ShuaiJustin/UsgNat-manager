### 2. 用户标识 ✅

```typescript
// 生成匿名设备ID（SHA256哈希）
private async getUserId(): Promise<string> {
  const identifier = `${hostname}-${macAddress}`;
  const hash = crypto.createHash('sha256')
    .update(identifier)
    .digest('hex');
  return hash.substring(0, 32);
}
```

### 3. 灰度发布 ✅

```typescript
// 服务器端控制
if (versionInfo.rolloutBlocked) {

}
```
