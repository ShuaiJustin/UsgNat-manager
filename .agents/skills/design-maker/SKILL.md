# 设计图制作

## 核心

创建或协调可直接实现的设计产物，让开发不靠猜。设计覆盖范围必须匹配产品需求。

## 输入

- `Product-Spec.md`。
- `Design-Brief.md`。
- 现有设计文件、截图或组件库。

## 产出

- 页面和组件清单。
- 状态覆盖清单。
- 可用时包含尺寸数据的实现说明。

## 规则

- 每条界面需求都要对应页面、组件或状态。
- 核心流程的默认、空、加载和错误状态不可省略。
- 新建组件前先复用现有组件。
- 使用真实内容，不使用装饰性占位文案。

## 检查清单

- [ ] 每个 P0 界面需求都有设计目标。
- [ ] 已识别可复用组件。
- [ ] 状态已覆盖。
- [ ] 已记录尺寸或设计参考。
