# 构建发布

## 核心

只发布已经在用户将收到的同类环境中构建、安装并检查过的内容。

## 输入

- `DEV-PLAN.md`。
- 构建脚本和部署目标。
- 环境与密钥要求。

## 产出

- 构建产物或部署步骤。
- 发布检查清单。
- 隐私和密钥审计结果。
- 验证证据。

## 规则

- 开发服务器通过不等于打包发布通过。
- 检查构建产物中的本机路径、密钥、数据库和隐私数据。
- 记录精确命令和输出。
- 发现隐私或凭据泄露时立即停止。

## 检查清单

- [ ] 构建命令已通过。
- [ ] 已测试打包产物。
- [ ] 密钥/隐私审计已通过。
- [ ] 发布说明准确。
