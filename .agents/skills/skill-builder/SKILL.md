# 技能生成

## 核心

只有当重复工作需要可复用的过程知识时，才创建新技能。优先改进现有技能，而不是新增。

## 输入

- 已批准的进化建议或用户明确请求。
- 高频任务示例。
- 现有技能列表。

## 产出

- 新建或修订的 `SKILL.md`。
- 仅在必要时附带 `references`、`scripts` 或模板。

## 规则

- 技能名称使用小写短横线格式。
- 文件头元数据只包含 `name` 和 `description`。
- `description` 字段要描述触发条件，不描述执行过程。
- 正文保持精炼。
- 不创建不会被技能直接使用的额外文档。

## 检查清单

- [ ] 现有技能无法覆盖该重复工作。
- [ ] 名称有效。
- [ ] 触发描述具体。
- [ ] 正文足够轻。
- [ ] 基本文件头元数据校验通过。
