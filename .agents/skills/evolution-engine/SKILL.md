# 进化消化

## 核心

把反馈信号整理成规则变更建议。不得自动应用变更；每条建议都由用户决定。

## 输入

- `.codex/evolution/signals.jsonl`。
- `AGENTS.md`、技能目录、钩子脚本和 `EVOLUTION.md` 中的现有规则。
- 最近的用户反馈。

## 产出

- 更新后的 `.codex/evolution/proposals.md`。
- 只有用户确认后才应用的规则变更。

## 规则

- 区分通用规则和项目专属偏好。
- 旧规则冗余或失效时，主动建议删除。
- 尽量让进化后的规则更少、更准。
- 用户拒绝后删除对应信号和建议。

## 检查清单

- [ ] 信号已按模式分组。
- [ ] 每条建议都标明目标文件。
- [ ] 需要用户确认。
- [ ] 已接受的变更保持精炼。
