# 设计规范生成

## 核心

把抽象审美转成具体设计决策。形态先于视觉：先确认产品形态、工作流和信息密度，再谈视觉打磨。

## 输入

- `Product-Spec.md`。
- 用户的设计偏好或参考。
- 现有 UI、截图或品牌约束。

## 产出

- 更新后的 `Design-Brief.md`。
- 布局、组件、状态、字体、颜色和交互决策。

## 规则

- 给具体选项，不问宽泛风格问题。
- 把“干净”“高级”“简单”等词翻译成可执行的界面属性。
- 为重要界面覆盖默认、加载、空和错误状态。
- 不添加无助于工作流的装饰功能。

## 检查清单

- [ ] 产品形态清楚。
- [ ] 信息密度已定义。
- [ ] 视觉方向有具体属性。
- [ ] 重要状态已列出。
- [ ] 与 `Product-Spec.md` 的冲突已标出。
