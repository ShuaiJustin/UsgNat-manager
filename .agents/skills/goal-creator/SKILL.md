# 自驱指令生成

## 核心

编写紧凑的 `/goal` 指令，明确目标、证据、约束和停止条件。由用户发送目标指令，代理不擅自启动自驱工作。

## 输入

- 当前 `DEV-PLAN.md` 阶段。
- 相关需求/设计上下文。
- 已知约束和验证命令。

## 产出

- 一条可供用户审阅的有边界 `/goal` 指令。

## 规则

- 指令要简洁，并以证据为中心。
- 完成标准必须能自我验证。
- 写明验证命令和必要审查门禁。
- 不把目标模式用于模糊产品决策或用户访谈。

## 检查清单

- [ ] 目标指令只有一个目标。
- [ ] 完成标准可衡量。
- [ ] 验证命令已写明。
- [ ] 边界和非目标明确。
